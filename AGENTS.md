# Instrucciones para trabajar en este repositorio

Al iniciar una sesión, leer `MEMORY.md` y `CLAUDE.md` para recuperar las reglas vigentes del proyecto.

Antes de revisar, generar, editar o informar el estado de imágenes de personajes, leer [Documentacion/seguimiento_personajes.md](Documentacion/seguimiento_personajes.md). Es el registro central de imágenes integradas, propuestas, aprobaciones y fechas.

Actualizar ese registro en el mismo cambio cuando se guarde una variante, se reciba una aprobación o se integre otra imagen. Conservar las fuentes y versiones anteriores. No inferir aprobación estética a partir de generación, subida o pruebas técnicas; no trasladar una aprobación a una versión distinta.
